## Ecosystem Support

### Protocols

Android does not restrict which presentation protocols a credential manager or verifier can use with the Digital Credentials API (web or native) or the credential manager APIs (for wallets).

### Credential Formats

Android does not restrict which credential formats a credential manager, issuer, or verifier can use with the Digital Credentials API (web or native) or the credential manager APIs (for wallets).

### Doc Types

Android does not restrict which document types a credential manager, issuer, or verifier can use with the Digital Credentials API (web or native) or the credential manager APIs (for wallets).
