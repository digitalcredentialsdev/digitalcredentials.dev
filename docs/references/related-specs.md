### ISO 18013-7 Mappings

The ISO 18013-7 specification can be confusing as it defines its own presentation protocol, as well as defines it's own references to other specifications.

- Annex **B**: refers to OpenID for Verifiable Presentations with custom schemes (`mdoc://`)
- Annex **C**: an mdoc-specific presentation protocol defined in this specification
- Annex **D**: refers to the OpenID High Assurance Interoperability Profile (HAIP)
